# 舞萌 13+ 五星进度表

国服舞萌 DX `13+` 五星（DX 分 ≥ 97%）社区难度表实时进度追踪工具，纯静态网页，部署在 GitHub Pages，方便手机/机厅随时查看。

在线地址：https://nakashimayuki.github.io/mai-13plus-5star/

## 功能

- **查分器实时同步**：支持落雪咖啡屋（`X-User-Token`，优先）与水鱼查分器（`Import-Token`），凭据与成绩仅存于本机浏览器 `localStorage`，直连官方接口。
- **自动划掉已 5★**：已达 5★ 自动压暗并打勾；未 5★ 曲绘底部显示距 5★ 差值（如 `5★ -5`），差值 ≤ 10 分高亮显示。
- **好BPM 标识**：按 60fps 帧对齐规律（`3600 % BPM === 0`），自动用节拍器角标标注好BPM 曲目（16 分整数帧亮金标，8 分 / 4 分整数帧金边标），支持一键筛选。
- **多视图与排序**：支持在「原版榜单」「按差值」「按定数」「按版本」之间一键切换，并叠加状态/难度/关键词筛选。
- **移动端秒开**：内置 361 张 `160×160` WebP 压缩曲绘缩略图，后续国服新增 13+ 自动回退落雪曲绘 CDN。
- **榜单编辑与导出**：开启「编辑榜单」可拖拽调档或移动端点击移档，支持自动检测国服新增 13+ 谱面并导出新版 `tier_list.json`。
